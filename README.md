# GunniBusch Gunnibush

## How do I install these formulae?

`brew install gunnibusch/gunnibush/<formula>`

Or `brew tap gunnibusch/gunnibush` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gunnibusch/gunnibush"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
